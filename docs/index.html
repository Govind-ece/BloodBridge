THE IDEA

Technology can help make connections simpler.

BloodBridge is a command-line Python project built to practise programming fundamentals through a meaningful use case. It lets users manage sample donor records and blood requests, then find possible matches using a simplified educational compatibility map.

ⓘ This website is a showcase for the project. It does not collect donor information or provide a live blood-matching service.
