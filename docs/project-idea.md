# BloodBridge — Project Idea

## Problem

During a blood emergency, finding a suitable donor can take valuable time. Information about blood groups, availability, and location may be difficult to search in an organized way.

## Proposed Solution

BloodBridge will be a Python-based educational application that stores donor information and matches suitable donors with simulated blood requests.

## Basic Flow

1. Register donors.
2. Submit a blood request.
3. Check blood-group compatibility.
4. Filter by availability.
5. Consider location.
6. Display suitable matches.

## Goal

Demonstrate the use of Python to solve a real-world humanitarian problem while keeping the project understandable and suitable for a Python class.

## Scope

This project is a prototype for educational purposes and will use fictional/sample data.
